# Kebs sample web (landing)

Static sample of the public site. **Not** the production Next.js app yet.

## Run

```bash
npm install
npm run dev
```

Open http://127.0.0.1:5173

| Path | What you see |
| --- | --- |
| `/` | Landing: hero, hook, how it works, features |
| `/verify` | Demo verify form (hardcoded codes, no Express) |

Demo codes on `/verify`: `7K4P2M9Q`, `A3N8R2T6`, `H9C1L5W2` (genuine) and `FAKE0001` (unknown).
